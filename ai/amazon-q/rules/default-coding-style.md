# Default Coding Style Rules

## Code Quality
- Write clean, readable code with minimal comments
- Use descriptive variable and function names
- Follow language-specific conventions
- Prioritize performance and security

## Documentation
- Include brief inline documentation for complex logic
- Update README files when adding new features
- Document API endpoints and data structures

## Testing
- Only write tests when explicitly requested
- Focus on critical path testing
- Use appropriate testing frameworks for the language
