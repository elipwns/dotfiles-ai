# Project Maintenance Rules

## Documentation Updates
- When adding features, update the README with usage examples
- When deleting features, remove related README sections
- When changing APIs or interfaces, update documentation immediately
- Include setup/installation steps for new dependencies

## File Management
- Remove unused imports and dependencies when deleting features
- Update requirements.txt/package.json when adding/removing dependencies
- Clean up configuration files when removing features

## Project Structure
- Maintain consistent folder structure across similar projects
- Keep configuration files in project root or dedicated config folder
